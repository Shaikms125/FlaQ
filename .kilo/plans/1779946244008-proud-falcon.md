# Plan: Redesign QuizCard Component

## Objective
Redesign the `QuizCard` component so that:
1. The **entire card is clickable** and navigates directly to the test (`/quiz/${accessCode}`).
2. A **three-dot menu** sits in the **top-left** with **Delete** and **Share** options (tracks `DropdownMenu` + `DeleteQuizDialog`/`ShareQuiz` with custom triggers).
3. The **bottom** has **Edit** and **Scores** buttons side-by-side with **zero gap** (`-ml-px` / `rounded-l-none` / `rounded-r-none` or a `flex` row with `-space-x-px`).

---

## Step-by-Step

### Step 1: Refactor `QuizCard.tsx`
**File:** `src/components/quiz/QuizCard.tsx`
- **Imports:** Add `DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuItem`, `DropdownMenuSeparator`, `IconDotsVertical`.
- **Structure:**
  - Wrap the entire card body in a clickable area (`onClick={() => navigate('/quiz/...')}`).
  - **Top-left:** Replace the old icon cluster with a three-dot vertical menu (dropdown). Inside the dropdown place:
    - **Share** — trigger `ShareQuiz` dialog via `trigger=<DropdownMenuItem asChild …>`.
    - **Delete** — trigger `DeleteQuizDialog` via `trigger=<DropdownMenuItem variant="destructive" asChild …>`.
  - **Bottom:** Remove `CardFooter` as a flex-wrap with gap. Use a `div` with `grid grid-cols-2` or `flex` with negative spacing so the two buttons sit flush (no gap, shared border radius `0` between them, rounded on outer corners).
- **Click propagation:** Dropdown trigger and bottom buttons must call `event.stopPropagation()` so they don't also navigate to the test.

### Step 2: Verify `ShareQuiz.tsx` & `DeleteQuizDialog.tsx` triggers
**Files:** `src/components/quiz/ShareQuiz.tsx`, `src/components/quiz/DeleteQuizDialog.tsx`
- Both already accept a `trigger` prop. Confirm `AlertDialogTrigger` and `DialogTrigger` render the provided trigger correctly (`render` prop pattern from Radix).
- Ensure `asChild` can be passed from `DropdownMenuItem` if needed.

### Step 3: Update Skeleton Layouts
**Files:** `src/pages/MyQuizzes.tsx`, `src/pages/Home.tsx`
- Match the skeleton placeholder to the new card layout (e.g., two bottom buttons flush, top three-dot menu icon).

### Step 4: Test & Verify Styles
- Card click navigates to test.
- Three-dot menu opens correctly; Share and Delete dialogs open cleanly from inside the dropdown.
- Edit / Scores buttons in the bottom are side-by-side with no visual gap.
- Stop propagation works on all inner controls.

---

## Trade-offs / Decisions
- Using a native `<button>` or `<span>` as the trigger for the dropdown and then `asChild` into the menu item is a common Radix pattern; the existing `render` prop on the dialogs may need a wrapper because `DropdownMenuItem` already expects an interactive child. We'll use the `render` prop with a minimal wrapper that forwards refs correctly.
